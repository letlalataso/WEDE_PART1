# Kwamsia and Foods Website

## 1. Project Description

Kwamsia and Foods is a fictional fast-food business based in Paarl, Western Cape, South Africa.

The purpose of this website is to provide customers with information about the business, its menu, food prices and contact details.

The website is designed for students, workers and community members who want quick, convenient and affordable meals.

**Documentation date:** 2 November 2026  
**Documentation time:** 13:38 (SAST)  
**Project status:** In development

## 2. Website Pages

The website consists of five HTML pages:

- Home – Introduces the business.
- About Us – Provides information about the business.
- Our Menu – Displays available meals and prices.
- Enquiries – Allows customers to make enquiries.
- Contact Us – Provides contact information and a contact form.

## 3. Technologies Used

- HTML5 – Used to structure the website.
- CSS3 – Used to style the website and create responsive layouts.
- JavaScript – Used to implement website functionality.

## 5. Responsive Design

The website uses CSS Grid, Flexbox and media queries to support desktop, tablet and mobile screen sizes.

Responsive images are implemented using HTML `srcset` and `sizes` attributes.

The website also uses relative CSS units such as `rem`, `em` and percentages to improve adaptability across different screen sizes.
